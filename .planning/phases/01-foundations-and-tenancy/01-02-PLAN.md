<threat_model>
## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Anonymous user -> Auth API | Public auth surfaces accept attacker-controlled input. | Email, password, reset requests |
| Auth API -> Session storage | Session and reset credentials cross into durable storage. | Session token digests, reset token digests, revocation metadata |
| API -> Email adapter | Sensitive recovery flows depend on outbound delivery. | Confirmation URLs, reset URLs |

## STRIDE Register

| threat_id | category | component | disposition | mitigation_plan | files_to_check |
|-----------|----------|-----------|-------------|-----------------|----------------|
| T-01-04 | Spoofing | Login/session issuance | mitigate | Hash passwords with Argon2, hash stored session tokens, sign HttpOnly cookies, and rotate/revoke sessions on password change. | apps/api/src/modules/auth/**; packages/db/src/schema/** |
| T-01-05 | Information Disclosure | Forgot/reset password flow | mitigate | Return generic success on reset request, hash reset tokens, set short expiry, single use, and never log raw links/tokens. | apps/api/src/modules/auth/**; packages/integrations/src/email/** |
| T-01-06 | Elevation of Privilege | Tenant settings access | mitigate | Resolve tenant from membership bound to the session and reject any attempt to pass tenant identity from the client. | apps/api/src/modules/tenants/**; apps/web/src/app/** |
</threat_model>
