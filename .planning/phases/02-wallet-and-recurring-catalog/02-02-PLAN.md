# Phase 2 Plan 02: Modulo de planos, assinaturas e regras basicas de dominio recorrente

## Objective
- **What:** Add plan and subscription lifecycle support to the wallet domain and expose it through authenticated API endpoints.
- **Why:** The product needs a recurring catalog before the charge engine can generate tenant-safe charges.
- **Output:** Plan/subscription schemas, repository support, audit-integrated service/controller layer, and e2e coverage.

  <verify>Every plan/subscription mutation has a validated payload contract in `packages/domain`.</verify>
</task>
